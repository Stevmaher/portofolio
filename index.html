The way I work

Start with structure.
Finish with feeling.

01

Understand the interface

I start by reducing the idea to its essential screens, content, hierarchy, and user actions. The goal is clarity before decoration.

02

Build close to the browser

HTML, CSS, and JavaScript stay at the core. TypeScript, React, Tailwind CSS, and Supabase enter when they make the product easier to scale and maintain.

03

Add motion with purpose

Interaction should explain hierarchy, give feedback, or make a moment memorable. That is why my motion stays restrained and intentional.

04

Ship something maintainable

Git and GitHub keep the work organized, while responsive layouts and performance-minded implementation keep the final interface practical beyond the first screen.
