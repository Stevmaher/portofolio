SaaS web application

Waad وعد

A clearer way for Egyptian merchants to manage installment sales, contracts and daily collections.

  • React
  • Vite
  • Tailwind CSS
  • Supabase
  • Capacitor

The problem

Installment sales involve customers, contracts, due dates and partial payments. Merchants need a clear view of what has been paid and what is still due.

The solution

An Arabic, right-to-left workspace that brings customer accounts, installment schedules and collection tasks into one responsive interface.

My contribution

Built the merchant-facing interface and connected account, contract and payment workflows to Supabase.

Key features

  • Merchant dashboard and daily collection queue
  • Customer records and contract ledgers
  • Generated payment schedules and partial-payment tracking
  • Subscription plans and account settings
  • Arabic RTL layouts and a separate sample-data preview

User workflows

A merchant starts the day from the dashboard's collection queue, opens a customer record to review its contract ledger, and records partial payments against the generated schedule.

Technical implementation

React components separate the dashboard, customer records and payment dialogs. Vite builds the app, Tailwind supports the UI, and Supabase handles authentication and data. Capacitor provides Android integration.

Database integration

Account, contract and payment workflows are read and written through Supabase, keeping merchant data behind authenticated access.

Challenge & approach

Payment state needs to stay consistent across installments and contracts. Shared installment logic calculates remaining amounts and contract status, while the interface refreshes after saved operations.

Algorithmic analysis tool

AXIOM

Animal merge analysis for Al-Fatehoon players, helping evaluate moves before committing in-game resources.

  • HTML
  • CSS
  • JavaScript
  • Web Workers
  • Supabase

The problem

Players need to explore merge decisions without spending resources on trial and error inside the game.

The solution

A board-based analysis interface for exploring equal-level merges, evaluating moves and following progression toward higher levels.

My contribution

Built the responsive analysis interface, board interactions and account-access flows.

Key features

  • Board-based animal merge and level analysis
  • Move suggestions and animated merge transitions
  • Level-11 merge progress tracking
  • Supabase authentication and subscription access checks
  • Arabic interface with responsive controls

Technical implementation

The interface uses native HTML, CSS and JavaScript. The analysis engine runs in a Web Worker and is retrieved through a Supabase Edge Function after account and subscription checks.

Challenge & approach

Analysis should not freeze the interface. Moving the engine into a Web Worker keeps board controls separate from search computation. Suggestions are analysis aids, not a guarantee of in-game results.

Bilingual travel website

VOYARA Travel

A bilingual travel landing page for an Egyptian audience, balancing a distinct visual identity with clear inquiry paths.

  • React
  • Tailwind CSS
  • Parcel

The problem

A travel website needs to make services easy to explore while feeling natural in both Arabic and English.

The solution

A responsive landing page with destination and package sections, travel services and clear contact calls to action.

My contribution

Built the landing-page components, responsive layouts and bilingual UI.

Key features

  • Arabic and English language switching
  • RTL and LTR layout support
  • Destination and travel-package presentation
  • Service, FAQ and inquiry sections
  • Contact-oriented calls to action

Technical implementation

React components share a language context and separate translation files. The active language updates document direction and metadata. Tailwind styles the interface and Parcel produces the static build.

Challenge & approach

Translation affects more than text. A shared language context keeps direction, locale and page metadata in sync as visitors switch languages.

Bilingual analytics dashboard

Glass Admin

A glassmorphism admin dashboard with a bilingual English and Arabic interface, draggable widgets and live analytics views.

  • React
  • Vite
  • Tailwind CSS
  • Framer Motion
  • D3

The problem

Admin dashboards often ship in English only and lock users into a fixed layout that does not match how they actually work.

The solution

A dashboard where every card can be moved, swapped and resized, with the full interface available in English and Arabic, including RTL layout.

My contribution

Built the interface, drag-and-drop layout system, bilingual content model and data visualizations end to end.

Key features

  • English and Arabic interface with full RTL support
  • Draggable and resizable cards with saved layout
  • Revenue, orders and sessions analytics with charts
  • Notifications drawer and command palette
  • Dark glassmorphism design with animated accents

Technical implementation

React with Vite, styled with Tailwind CSS. Framer Motion drives the animated interactions, and D3 renders the geographic and chart visualizations. Dates and activity data are generated dynamically so the demo always shows current periods.

Challenge & approach

Bilingual support is more than translation. Layout direction, mirrored controls and Arabic typography all change with the language, so the layout system was built direction-aware from the start.
